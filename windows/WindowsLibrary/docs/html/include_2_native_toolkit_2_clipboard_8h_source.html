218 // --- The synchronous core (OP-25..OP-39) -------------------------------
219 //
220 // Callable from any thread. Each one opens and closes the clipboard for

222 //
223 // A wstring_view argument is read only up to its own length: it does not
224 // have to be NUL terminated, and a view into the middle of a larger string
