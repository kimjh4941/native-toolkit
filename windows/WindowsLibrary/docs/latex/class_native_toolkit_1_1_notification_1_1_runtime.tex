\doxysubsection{Detailed Description}
The Windows App \doxylink{class_native_toolkit_1_1_notification_1_1_runtime}{Runtime}, held for as long as notifications are used. 

Only an unpackaged app needs this\+: a packaged one already has the runtime. Destroying the token shuts the bootstrapper down again, which the 1.\+x C ABI never did\+: init\+Win\+App\+Sdk had no counterpart and left the runtime loaded for the life of the process (N-\/7). The 2.\+x C ABI has the matching pair as well -\/ ntk\+\_\+notification\+\_\+runtime\+\_\+free shuts it down, waiting for the last manager to close first.

Move only, because shutting the runtime down twice is not the same as shutting it down once.
