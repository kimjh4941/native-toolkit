\doxysubsection{Detailed Description}
Value types shared by every feature of the C++ API. 

Part of the public C++ API added in stage 3 of the windows-\/architecture topic. The public headers never include \texorpdfstring{$<$}{<}windows.\+h\texorpdfstring{$>$}{>}\+: a consumer that has not included it still gets a usable Window\+Handle, and one that has gets the very same type as HWND.

Keep this header ASCII only. A non-\/\+ASCII byte forces every consumer to compile with /utf-\/8 or see warning C4819.
