\doxysubsection{Detailed Description}
\subsubsection*{template$<$class T, class E$>$\newline
class Native\+Toolkit\+::\+Result$<$ T, E $>$}
Either a value of type T or a failure of type E. 

Copyable only when both T and E are; \doxylink{class_native_toolkit_1_1_result}{Result$<$\+Session$>$} and \doxylink{class_native_toolkit_1_1_result}{Result$<$\+Manager$>$} are therefore move only. Trivially destructible when both T and E are, so a \doxylink{class_native_toolkit_1_1_result}{Result} of plain values costs nothing to destroy. \doxylink{class_native_toolkit_1_1_result_ae94e85e7ba2d15b2162e22c10f6e4e6d}{value()} and \doxylink{class_native_toolkit_1_1_result_a54e81884c4db5a7ffa27140457d63010}{error()} are unchecked\+: calling the wrong one is a precondition violation, asserted in debug builds, and never throws.
