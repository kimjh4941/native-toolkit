\doxysubsection{Detailed Description}
Win32 clipboard operations (synchronous, RAII-\/guarded). 

Thin, mechanical wrapper over the Win32 clipboard API. Every entry point opens the clipboard, performs one operation, and closes it. Ownership of clipboard-\/bound memory (Global\+Alloc handles) is tracked with RAII so a handle is freed on every failure path and released to the system exactly once, on success.
