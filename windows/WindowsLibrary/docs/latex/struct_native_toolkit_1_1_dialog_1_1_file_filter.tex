\doxysubsection{Detailed Description}
One entry of a file dialog\textquotesingle{}s type list. 

The 1.\+x C ABI took the Win32 block directly\+: pairs of strings separated by NULs and terminated by two (DLG-\/12). This is that block as data. An entry with no patterns matches everything.
