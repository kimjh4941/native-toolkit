\doxysubsection{Detailed Description}
Public C Bridge API for the Windows Clipboard Manager. 

Provides clipboard copy/paste (text, HTML, files, images, custom formats), content inspection, change monitoring, deferred rendering, and clipboard history access via Win\+RT Windows.\+Application\+Model.\+Data\+Transfer.\+Clipboard. Minimum OS\+: Windows 11.

See artifact/designs/clipboard/2026-\/07-\/28-\/windows-\/clipboard-\/design-\/v2.\+md for the full concurrency and lifecycle contract summarized in the notes below.
