\doxysubsection{Detailed Description}
Pure-\/logic helpers for clipboard payload construction and validation. 

No Win\+RT or live clipboard dependency\+: safe to unit test directly. Every function treats its input as untrusted (either about to be written to the clipboard, or read back from it) and never throws.
