\doxysubsection{Detailed Description}
What every part of the Native\+Toolkit C ABI shares\+: the version, the last system code, and the three output handles (a string, bytes and a list of strings). 

Rules that hold for the whole C ABI (stage 5 design, sections 1 and 7)\+:
\begin{DoxyItemize}
\item Strings are NUL-\/terminated UTF-\/8, in and out.
\item Every handle a function hands out is released with its own \+\_\+free, and \+\_\+free(\+NULL) does nothing. Pointers read from a handle stay valid until that handle is freed.
\item A failing function reports its error as the return value; the raw value the OS gave, if any, is \doxylink{_common_8h_abeeebfcaf748e3130c1abc2f4f17e124}{ntk\+\_\+last\+\_\+system\+\_\+code()} on the same thread.
\item The header is plain C99, includes nothing but \texorpdfstring{$<$}{<}stddef.\+h\texorpdfstring{$>$}{>} and \texorpdfstring{$<$}{<}stdint.\+h\texorpdfstring{$>$}{>}, and is ASCII only. 
\end{DoxyItemize}
