\doxysubsection{Detailed Description}
The clipboard session and the values its operations exchange. 

Part of the public C++ API added in stage 3 of the windows-\/architecture topic (design sections 7.\+4.\+1 and 8). This header carries the session and its lifetime; the synchronous operations, deferred rendering and the history arrive with OP-\/25..OP-\/47.

Keep this header ASCII only.

Produces the bytes of a reserved format, when something asks for them. 

Called on the thread that owns the session, from inside the message the OS sends to collect the data. That places three hard limits on what it may do\+: it must not call any clipboard operation, including this session\textquotesingle{}s own; it must not block, because the asking application is waiting; and it must not capture the session, which would be a cycle.

Returning a failure, or throwing, means the format renders as nothing\+: by then the reservation has been made and the asking application is mid-\/paste, so there is no one left to report to. Both are logged.
