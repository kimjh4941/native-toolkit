\doxysubsection{Detailed Description}
What to be told about the history. 

Passing a default-\/constructed value unregisters every handler.

Handlers arrive on the thread that created the session, and are not moved to any other (CLP-\/04). on\+History\+Changed fires when an item is added, not when one is removed or the history is cleared (CLP-\/31).
