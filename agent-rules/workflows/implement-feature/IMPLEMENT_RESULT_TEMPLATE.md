## 6. Definition of Done

- 判定基準:
  - ○: 今回の実装・コード・テスト確認の範囲では OK かつ設計書とズレていない
  - △: 一部 OK だが、追加確認が必要
  - ×: 未達、または設計書との差分が未解消
  - -: 対象外
- ○ / △ / × / - <DoD item 1>
- ○ / △ / × / - <DoD item 2>
- ○ / △ / × / - <DoD item 3>
