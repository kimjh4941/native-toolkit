| RA-1 | 両方（Claude A-1、Codex A-02） | N24・NC3 の保留を解く `Reply` の確かめが、この Mac で通知センターの一覧（私物の通知）を開きうるのに、そのことを示した別の許可が無い。一覧が開いたかの判定と、途中で残ったときの扱いも無い | U-30 で `Reply` の確かめを別の段（`--qualification mac26-reply`）に分け、その段の `--dry-run` の一覧と 6.5 に「通知センターの一覧が開き、私物の通知が画面と収録に出うる」と書き、別の許可にした。判定は読むだけの口で `Reply` の前と後の通知センターの窓の数と枠を比べる。開いたら `NTK-STOP:notificationUI` で止める（適格性の段にも当てると 5.0 に書いた）。この段を許さない利用者には、利用者が自分で 1 回試す形を示す |
| RA-2 | Codex A-01（Claude B-1 も） | 押す前の確かめが、通知の操作にもサンプルの前面を求めるので、後ろの状態（N21・N23・N24）とコールドスタート（NC1〜NC3）で押せない | 5.0 を押す相手ごとの条件にした（サンプルの窓の要素、パネルの要素、通知のバナー・`Options`・メニュー、キー入力）。通知の操作はサンプルの状態を筋書きのとおり（前面・後ろ・`notRunning`）とし、点が根の枠の中で、覆う最前面の窓の持ち主が通知センターであることを求める。後ろとコールドスタートで押せること、想定外の状態で操作が 0 回になることを 7 章に足した |
| RA-3 | Claude A-2 | 強制終了の後の片付けが、再起動の後に使い回された PID・process group の番号で私物のプロセスを止めうる | 印に起動の時刻と、書き手ごとの PID・開始時刻・実行ファイルの実体のパスを書き、3 つがすべて一致するときだけ止める。process group へは leader が一致し、中身がテストの道具だけのときに限る。印が今の起動より前なら止めずにフォルダーだけを消す。取り違えの入力で止めないことを 7 章の自己テストに足した |
