## 区分 B

| # | 出典 | 指摘 | 直したこと |
|---|---|---|---|
| RB-1 | 両方（Claude B-2、Codex B-02） | `Reply` の前後の窓の数と枠から「一覧が開いた」を決める規則が無く、バナーの中で広がっただけでも枠は変わる | 純粋な関数 `classify_reply_state` で「一覧」「バナーの中で入力できる」「分からない」に分ける規則（前提、観測の期間、窓の増加と枠の広がりの基準、焦点を持つ欄）を U-30 に書いた。「一覧」と「分からない」は保留を解かず止める。15 の VM で「一覧」と判定できることを 9.1 で確かめてから使い、変化なし・関係の無い窓・欠けた値の fixture で自己テストする |

| RB-4 | Codex B-03 | U-29 の照らしの語と許した出現を照合する処理の合否の例が無い | 7 章に、この Mac でテストを起動しない自己テスト（許していない `resolve(.general)` と `MacClipboardManager.shared` を拒む、一致する mock の出現を受ける、不一致を拒む、照らしを弱める変異で落ちる）を足した |
