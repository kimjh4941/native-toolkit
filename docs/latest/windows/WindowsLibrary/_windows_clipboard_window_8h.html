Detailed Description

Creates/destroys the toolkit-owned dispatch window (dispatchHwnd).

A hidden top-level window (not HWND_MESSAGE - see design notes) with its own WndProc, used as: the SetClipboardData owner for delayed rendering, the AddClipboardFormatListener target, and the UI-thread dispatch target for history requests/cancel/drain messages. Routes messages to the ClipboardManager singleton.
