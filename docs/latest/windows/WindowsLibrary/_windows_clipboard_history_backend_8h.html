Detailed Description

Port for clipboard history access (Domain types only; no winrt:: types).

Request methods are asynchronous (completion callback) even where the underlying WinRT API is synchronous (GetAvailabilityAsync), because the Port must let a mock control completion timing for pending/cancel/drain tests. Event-value queries are synchronous and owner-UI-thread-only.
