AndroidShareManager

class AndroidShareManager

The entry point for sharing (Kotlin API design 6.3, 8.9).

The existing operations take the same arguments and give the same results and exceptions as ShareUseCases; custom chooser actions are typed, through shareTextWithActions. This class only delegates; it keeps no Activity.
