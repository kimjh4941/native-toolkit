ClipboardUseCases

class ClipboardUseCases(repository: ClipboardRepository)

Use-case suite for clipboard operations.

Exposes all clipboard use cases as properties for convenient access.

Note: Clipboard change observation is not part of this suite. It is owned by the Manager layer (ClipboardChangeMonitor) and does not go through a UseCase / Port.
