AndroidClipboardManager

class AndroidClipboardManager

The entry point for the clipboard (Kotlin API design 6.3, 8.10).

The existing operations take the same arguments and give the same results and exceptions as ClipboardUseCases. Observation is one per process and shared by every listener of changes. This class only delegates; it keeps the Application Context only.
