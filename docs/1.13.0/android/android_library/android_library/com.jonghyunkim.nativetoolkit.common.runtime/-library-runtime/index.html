LibraryRuntime

object LibraryRuntime

Initializes the parts of the library that need the Application (Kotlin API design 8.1).

LibraryInitializer calls ensureInitialized at app start through androidx.startup. Apps that disable Startup call it themselves, for example from Application.onCreate or the first Activity's onCreate. APIs that need the foreground Activity (dialogs, the notification permission request) complete with NOT_INITIALIZED until this has succeeded; the other APIs work without it, as before.
